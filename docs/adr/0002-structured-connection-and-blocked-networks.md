# 数据源只收结构化连接字段，并按必配的禁止网段拦截连接

Tenant 登记 Data Source 时不能填写 JDBC URL 或任意连接参数，只能填主机、端口、库名、账号、密码与按类型白名单列出的参数，由服务端拼装 URL；连接前解析域名，落入服务必配的禁止网段（平台内网）即拒绝，API 数据源同样处理且不跟随重定向。原因是服务端代租户发起连接：自由填写的 URL 可携带已知可被利用的驱动参数（如 MySQL 的 `allowLoadLocalInfile`、PostgreSQL 的 `socketFactory`），不加网段限制则租户可借服务探测或攻击平台自身的数据库、Redis、Nacos。禁止网段不设默认值，漏配启动失败，因为各环境的内网划分不同，错误的默认值比启动失败更危险。

## Consequences

- 需要特殊驱动参数的租户只能等白名单扩充，不能自助配置。
- 租户自有数据库与平台同处一个内网时无法连接，需由部署方调整禁止网段或网络拓扑。
