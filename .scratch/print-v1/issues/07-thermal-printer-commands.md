# 07: 热敏指令：位图 ZPL/TSPL

**What to build:** 同一张标签能导出 ZPL 与 TSPL 指令，发给热敏标签机打出来的结果与 PDF 预览一致，中文不依赖打印机字库。多张标签按批导出，指令文本可下载或由前端取走。

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 标签按 203 / 300 / 600 dpi 栅格化为 1-bit 位图；毫米尺寸是模板真值，dpi 只决定像素
- [ ] ZPL 导出：每张标签一条 `^XA … ^XZ` 指令块，位图走 `^GFA`；TSPL 导出：逐张设置尺寸与间隙，位图走 `BITMAP`，以 `PRINT` 结束
- [ ] 多张标签按批返回指令数组，批次上限与 06 的多页上限一致
- [ ] 指令中的位图来自与 PDF 相同的 HTML 渲染，因此文字位置、条码与预览一致
- [ ] 指令测试：位图尺寸与 dpi 换算、ZPL/TSPL 指令骨架逐字比对
- [ ] 不实现打印机连接、发送、状态回传；接口只返回指令文本
- [ ] 栅格化失败（元素越界、字体缺失）时返回可读错误，不返回残缺指令
