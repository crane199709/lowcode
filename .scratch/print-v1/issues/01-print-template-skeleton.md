# 01: 打印模板骨架：文档模板的段落与字段

**What to build:** 持 `print-template:manage` 的成员能在打印模板列表新建一个文档模板、绑定一个 Dataset，在编辑器里搭出「段落 + 字面文本 + 字段占位」的版式，保存草稿、发布出修订号，并在 iframe 里看到服务端渲染的 HTML 预览。这一刀同时立起打印域的骨架：模板表、修订表、引擎包边界、三个权限码与数据资源声明。一期只开放文档模板，标签模板在 06 开放。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 打印模板列表、详情、新建、编辑、删除的接口与页面可用；模板类型在创建时确定且不可变更；创建时间、发布状态、当前修订号在列表可见
- [ ] 文档模板的内存模型包含纸张与边距、页眉、页脚、覆盖层、正文区块列表；一期正文只支持 `paragraph` 与其行内节点，未知节点在保存与发布时都被拒绝
- [ ] 草稿随模板聚合根保存，并发编辑用乐观锁，冲突返回可读错误而不是覆盖
- [ ] 发布生成不可变修订：修订号在同模板内递增，记录发布人与时间与变更说明；内容摘要相同不产生新修订
- [ ] 服务端把模板快照合成为一份自包含 HTML（内联 CSS、无外部请求、禁止脚本与事件属性），编辑器预览直接加载它；这份 HTML 是后续 PDF 与位图的唯一来源
- [ ] 引擎包只依赖 JDK，不依赖 Spring、JDBC、租户、Dataset、存储，由架构规则测试守住
- [ ] 权限码 `print-template:view`、`print-template:manage`、`print-template:publish` 在 Manifest 声明并生效；查看、编辑、发布各自鉴权
- [ ] 模板表按租户隔离（与现有表同样的 RLS 策略），声明数据资源使「本人」「本部门」可限制可见模板
- [ ] 发布前结构校验：节点白名单、必填属性、非法取值一律拒绝，返回可读原因
- [ ] 引擎 golden HTML 回归与前端列表、编辑器视觉回归各有用例

**Comments**

- 一期不做的事项在此确认：不做自由 HTML 模板、不做标签模板、不做正文内页码（见 03）。
- 数据策略与 RLS 跟第一张表一起落地，因此 09 只承担引用保护与生命周期。
