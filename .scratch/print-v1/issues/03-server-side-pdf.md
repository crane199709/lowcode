# 03: 服务端 PDF：页面、页眉页脚与产物

**What to build:** 成员能把文档模板导出成 PDF，且 PDF 与编辑器里的预览一致：纸张尺寸、方向、边距生效，页眉页脚按「每页 / 仅首页」显示，`[page]` / `[total]` 页码正确，中文不出豆腐块。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 纸张取 A3 / A4 / A5 / 自定义（毫米，正数），方向纵向 / 横向，四边边距毫米生效；超出范围的取值在保存时拒绝
- [ ] 页眉页脚按显示策略渲染：每页 / 仅首页；内容限于文本、字段、图片与对齐，编辑器里就不能插入表格
- [ ] `[page]` 与 `[total]` 在页眉页脚正确显示；该限制在编辑器里显式提示（正文内不支持页码）
- [ ] 镜像内置开源中文字体，模板只能从白名单选字体族与字号；启动时做一次基准渲染自检，字体缺失则启动失败
- [ ] 无头 Chromium 缺失时启动失败并给出可读原因，不静默降级为「没有 PDF」
- [ ] 同一份 HTML 既是 iframe 预览也是 PDF 来源，二者内容一致（不以截图比对代替，靠同源保证 + 关键度量断言）
- [ ] PDF 冒烟测试断言页数与页面尺寸；Chromium 不可用时跳过并显式告警，不静默通过
- [ ] 导出走同步请求，单次上限页数在 08 统一处理，本切片先给出明确错误码
