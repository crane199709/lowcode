# 05: 模板资源与覆盖层

**What to build:** 机构标志、印章、签名、背景图能上传并在模板里使用；背景图与文本/图片水印在 PDF 的每一页都出现；印章与签名渲染为「图片 + 名称 + 时间」三件套。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 模板资源上传：PNG / JPEG，单文件不超过 2 MiB，用独立的 Storage Purpose 存放；列表、预览、删除可用
- [ ] 资源被模板草稿或任一修订引用时禁止删除，返回引用清单
- [ ] 图片区块可用：静态资源图或字段图（字段值为资源标识），可配尺寸与适应方式
- [ ] 覆盖层可用：背景图（铺满 / 适应）、文本水印（旋转角、透明度、颜色、平铺）、图片水印
- [ ] 覆盖层在 PDF 每页重复，在预览里同样每页可见；用 PDF 断言覆盖层元素在每一页出现
- [ ] 印章与签名分别渲染为图片 + 名称 + 时间；字段缺失时按缺失策略处理
- [ ] 资源读取失败、资源已删除时渲染失败并指出是哪个资源，不输出空白方块
