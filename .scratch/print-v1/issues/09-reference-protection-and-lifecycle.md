# 09: 引用保护与模板生命周期

**What to build:** 数据集被打印模板引用时删不掉，删除模板要满足条件，下线后模板不再出现在打印页。防止「删了 Dataset，几个月后才发现一堆模板绑着它」。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Dataset 被打印模板的草稿或任一修订引用时禁止删除，返回引用清单（模板名与修订号），与现有引用保护返回结构一致
- [ ] 数据源被 Dataset 引用这条既有保护不受影响，打印域不新增数据源引用
- [ ] 模板下线后：打印页不再列出、已发布修订保留、可重新上线
- [ ] 模板删除只在「从未发布且无草稿内容」或「已下线」时允许；删除时清理其修订与专属资源
- [ ] 删除为逻辑删除，与现有资源一致
- [ ] 集成测试覆盖：引用中删除被拒、解除引用后可删、下线后打印页不可见、删除清理资源
