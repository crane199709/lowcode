# 02: 绑定数据：契约派生与真实数据预览

**What to build:** 编辑器的字段面板从模板绑定的 Dataset 自动列出字段，字段可以插入段落；预览用真实查询结果渲染；字段格式化与缺失策略生效；发布前的预检能拦下「绑定了不存在的字段」。成员不必再手写数据契约——契约由 Dataset 已有的字段元数据派生。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 编辑器字段面板列出 Dataset 的字段：显示名、类型、维度/度量、是否日期，与 Dataset 页展示一致
- [ ] 字段插入段落生成占位，绑定点号路径；数组与对象字段在面板里按层级展开
- [ ] 格式化后缀生效：日期、整数、两位小数、千分位、百分比；非法格式化在保存时拒绝
- [ ] 预览用真实查询结果渲染（取首行），空结果时给出可读提示而不是空白页
- [ ] 缺失策略默认 `error`：字段缺失时渲染失败并指出是哪个路径；元素可单独配置为留空
- [ ] 发布预检拦下：绑定字段不在 Dataset 里、字段类型与格式化不兼容
- [ ] 契约不落库，由 Dataset 字段派生；Dataset 字段变更后，模板预览反映新字段，旧绑定失效时按缺失策略处理
- [ ] 引擎侧覆盖格式化的 golden HTML 用例，以及缺失策略两种取值的用例
