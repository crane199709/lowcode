# 06: 标签模板与条码

**What to build:** 成员能在毫米画布上拖拽搭出小尺寸标签：文本、字段、条码、二维码、线、矩形、图片、日期；预览即时显示可扫的条码；一份查询结果打成多页 PDF，每页一张标签；越界元素在发布时被拒绝而不是被裁掉。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] 模板类型增加标签模板，与文档模板共用草稿、修订、发布与资源能力；类型创建后不可变更，两种类型的格式不能混用
- [ ] 标签编辑器：毫米画布，元素拖拽与缩放，1mm 吸附，属性面板，边距参考线
- [ ] 元素白名单 8 种：文本、字段、条码、二维码、线、矩形、图片、日期；未列入的类型被拒绝
- [ ] 条码码制 CODE128 / EAN13 / CODE39，二维码 QR；可配模块宽度、条高、静区、是否显示人读字符
- [ ] 条码值规范化：去空格、补校验位、长度校验；不合法时渲染失败并指出原因，不产出不可扫的码
- [ ] 文本换行策略三种：缩放、换行、裁切，并可限制最大行数
- [ ] 一份查询结果的每一行渲染成一张标签，产物为多页 PDF，每页一张
- [ ] 元素超出标签边界、字号溢出导致无法排布时，发布预检拒绝
- [ ] 标签编辑器与条码预览有视觉回归用例
