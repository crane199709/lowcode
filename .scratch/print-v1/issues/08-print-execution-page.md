# 08: 打印执行页

**What to build:** 成员能在独立打印页选模板、填参数、预览、打印或下载/导出，一条链路覆盖文档模板与标签模板，不再需要进编辑器才能出纸。

**Blocked by:** 04, 06

**Status:** ready-for-agent

- [ ] 打印页列出当前可见的已发布模板；未发布的模板不可选，并给出可读说明
- [ ] 模板可声明打印参数：名称、类型、是否必填、默认值，映射到 Dataset 的可过滤字段与运算符（等于、包含于、区间）；参数在页面上渲染成表单
- [ ] 参数值作为查询过滤条件注入现有取数路径，不改造 Dataset 模型；必填未填时拒绝执行
- [ ] 预览、浏览器打印（预览 iframe）、下载 PDF、导出指令四条出口都可用
- [ ] 上限生效：文档模板不超过 50 页、标签模板不超过 200 张，超限直接拒绝并提示缩小查询范围
- [ ] 取数用当前用户身份；无数据或数据范围不允许时给出可读提示，不是空白页或 500
- [ ] 执行打印不落库、不建任务表；只有显式的归档动作才把产物写入平台存储
- [ ] 前端视觉回归覆盖参数表单、空结果与超限拒绝三种状态
