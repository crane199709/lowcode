# 04: 声明式表格与跨页

**What to build:** 模板能放表格并跨页：列由列定义声明，行来自数组，长表格自动分页且每页重复表头，行不会被切两半。这是「报告单」真正可用的那一刀——在此之前文档模板只能打固定几行。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] `table` 区块支持列定义：标题、绑定、宽度、对齐、格式化、缺失策略；列宽之和与页面可用宽度不匹配时给出可读提示
- [ ] 数组行绑定 `repeatOver`：单元格绑定相对当前行；数组为空时按配置显示空表或整块隐藏
- [ ] 跨页：表头每页重复，行不被切分，最后一行结束后不产生空白页
- [ ] 跨页在 PDF 中验证（03 的产物），断言页数、每页表头出现次数与页脚页码正确
- [ ] 其余文档区块补齐：键值栅格、列表、分隔线、强制分页、留白
- [ ] 可见性条件生效：存在、等于、不等于、包含于、布尔；条件不满足时元素不占位
- [ ] 嵌套限制生效：容器不超过 2 层，表格单元格内只允许文本与字段；违反时保存与发布都被拒绝
- [ ] 引擎 golden HTML 覆盖跨页表格结构、可见性两种取值、强制分页
