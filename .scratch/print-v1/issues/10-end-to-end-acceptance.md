# 10: 端到端验收

**What to build:** 在隔离平台上跑通真实链路，证明打印域能交付：设计者建模板、发布、查看者打印文档与标签、下载热敏指令、越权与数据范围被拒。

**Blocked by:** 05, 07, 08, 09

**Status:** ready-for-agent

- [ ] 隔离平台验收：登记数据源与数据集、建文档模板与标签模板、发布、打印页取数、下载 PDF、导出 ZPL 与 TSPL
- [ ] 越权验证：无 `print-template:view` 不能访问模板与打印页；无 `publish` 不能发布；数据范围外的模板不可见
- [ ] 校验产物：PDF 页数与尺寸符合模板；ZPL/TSPL 指令打印或经解析后与预览一致
- [ ] 视觉回归基线覆盖模板列表、文档编辑器、标签编辑器、打印页，两种宽度各一套
- [ ] 验收记录写入 `.scratch/print-v1/acceptance.md`，包含执行时间、平台版本、覆盖范围与未验证边界
