# 13: 其余图表组件

**What to build:** 编辑器中能放置并配置基础折线图、堆叠柱状图、饼图（含环形开关）。见规格第 5 节。

**Blocked by:** 10

**Status:** ready-for-agent

- [ ] 折线图：一个 Dimension（常为日期）+ 一个或多个 Measure
- [ ] 堆叠柱状图：两个 Dimension（类别与堆叠）+ 一个 Measure
- [ ] 饼图：一个 Dimension + 一个 Measure；环形开关设置内半径
- [ ] 各组件属性面板只允许合法的 Field 组合，并给出提示
- [ ] 视觉用例覆盖每种组件，走查查看截图
